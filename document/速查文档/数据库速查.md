# MySQL 数据库速查

本文档对应后端 Java `entity/` + `mapper/` 中 MyBatis-Plus 实际映射的九张表（截至 v4.2）。

当前项目 MySQL 用途：
- **用户认证** (`sys_user`) — 登录注册、BCrypt 密码
- **会话元数据** (`chat_metadata`) — 会话列表、标题、时间
- **文档入库追踪** (`document_metadata`) — 上传状态机、Python Worker 回写
- **知识卡片** (`knowledge_card`) — AI 提取 + 手动创建的知识卡片 CRUD
- **卡片分组** (`card_group`) — 树形分组层级，`normalized_name` 去重
- **卡片关联** (`card_relation`) — 卡片间关联边（related_to/contains/precedes/derived_from）
- **关键词实体** (`keyword`) — 归一化关键词，支持层次和领域分类
- **卡片-关键词** (`card_keyword`) — 多对多关联，`source` 区分 AI/手动
- **关键词关系** (`keyword_relation`) — 同义词/上下位等语义关系

## 二、表结构

### 2.1 `sys_user` — 系统用户表

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | `BIGINT` | PK, AUTO_INCREMENT | 主键 |
| `username` | `VARCHAR(64)` | NOT NULL, UNIQUE | 账号 |
| `password` | `VARCHAR(255)` | NOT NULL | BCrypt 哈希 |
| `nickname` | `VARCHAR(64)` | NOT NULL | 昵称 |
| `role` | `VARCHAR(32)` | NOT NULL, DEFAULT `'USER'` | `USER` / `ADMIN` |
| `created_at` | `DATETIME` | NOT NULL, DEFAULT `CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME` | NOT NULL, ON UPDATE | 更新时间 |

Java 实体：`SysUser.java`，Mapper：`SysUserMapper.java`

**索引**：`uk_username` (UNIQUE)

### 2.2 `chat_metadata` — 会话元数据表

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | `BIGINT` | PK, AUTO_INCREMENT | 主键 |
| `user_id` | `BIGINT` | NOT NULL, FK → `sys_user.id` | 所属用户 |
| `title` | `VARCHAR(255)` | DEFAULT NULL | 会话标题（LLM 生成，用户可改） |
| `session_id` | `VARCHAR(128)` | NOT NULL, UNIQUE | 会话唯一标识 = RustFS 对象 Key |
| `created_at` | `DATETIME` | NOT NULL, DEFAULT `CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME` | NOT NULL, ON UPDATE | 更新时间 |

Java 实体：`ChatMetadata.java`，Mapper：`ChatMetadataMapper.java`

**索引**：`uk_session_id` (UNIQUE), `idx_user_id` (KEY)

> **注意**：对话正文 JSON 存储在 RustFS `fish-chat` 桶，此表仅存元数据（标题、行数）。服务层查询会话列表时走 `user_id` 索引。

### 2.3 `document_metadata` — 知识库文件上传任务表

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | `BIGINT` | PK, AUTO_INCREMENT | 主键 |
| `task_id` | `VARCHAR(64)` | NOT NULL, UNIQUE | 全局追踪 ID（UUID），Redis Stream 消息 + 前端轮询凭证 |
| `user_id` | `BIGINT` | NOT NULL, FK → `sys_user.id` | 上传者 |
| `file_name` | `VARCHAR(255)` | NOT NULL | 原始文件名（前端列表展示） |
| `file_size` | `BIGINT` | NOT NULL, DEFAULT 0 | 文件字节数 |
| `minio_path` | `VARCHAR(512)` | NOT NULL | RustFS `fish-docs` 桶内路径，Python Worker 据此下载 |
| `scope_type` | `VARCHAR(16)` | NOT NULL, DEFAULT `'PRIVATE'` | `PRIVATE` → `fish-user-knowledge` / `PUBLIC` → `fish-public-knowledge` |
| `status` | `VARCHAR(16)` | NOT NULL, DEFAULT `'PENDING'` | 状态机（见下方） |
| `error_msg` | `TEXT` | DEFAULT NULL | 失败详情或成功警告 |
| `chunk_count` | `INT` | DEFAULT NULL | Python Worker 写入 ES 的切片数 |
| `created_at` | `DATETIME` | NOT NULL, DEFAULT `CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME` | NOT NULL, ON UPDATE | 更新时间 |

Java 实体：`DocumentMetadata.java`，Mapper：`DocumentMetadataMapper.java`

**索引**：`uk_task_id` (UNIQUE), `idx_user_id` (KEY), `idx_status` (KEY)

**状态机**：

```
PENDING → PROCESSING → SUCCESS (chunk_count > 0)
                     → FAILED    (error_msg 非空)
```

## 四、关键查询模式

| 场景 | SQL / MyBatis-Plus 等价 | 使用的索引 |
|------|--------------------------|-----------|
| 登录查用户 | `SysUserMapper.selectOne(Wrappers.<SysUser>lambdaQuery().eq(SysUser::getUsername, username))` | `uk_username` |
| 当前用户会话列表 | `ChatMetadataMapper.selectList(Wrappers.<ChatMetadata>lambdaQuery().eq(ChatMetadata::getUserId, uid).orderByDesc(ChatMetadata::getUpdatedAt))` | `idx_user_id` |
| 按 session_id 查会话 | `ChatMetadataMapper.selectOne(Wrappers.<ChatMetadata>lambdaQuery().eq(ChatMetadata::getSessionId, sid))` | `uk_session_id` |
| 按 task_id 查文档状态 | `DocumentMetadataMapper.selectOne(Wrappers.<DocumentMetadata>lambdaQuery().eq(DocumentMetadata::getTaskId, taskId))` | `uk_task_id` |
| 用户文档列表（分页） | `DocumentMetadataMapper.selectPage(page, Wrappers.<DocumentMetadata>lambdaQuery().eq(DocumentMetadata::getUserId, uid).orderByDesc(DocumentMetadata::getCreatedAt))` | `idx_user_id` |
| 管理员全部文档列表 | 同上但无 `user_id` 过滤 + `scope_type` 区分 Tab | — |
| Python Worker 更新状态 | `UPDATE document_metadata SET status=%s, chunk_count=%s, error_msg=%s WHERE task_id=%s` | `uk_task_id` |

## 五、Python Worker 侧的访问

Python Worker (`fish_worker/db/mysql.py`) 使用 PyMySQL，`threading.local()` 每线程独立连接，`ping(reconnect=True)` 自动重连。

**仅在 `processor.py` 中写 MySQL**：
- 开始处理：`UPDATE status='PROCESSING'`
- 成功：`UPDATE status='SUCCESS', chunk_count=N`
- 失败：`UPDATE status='FAILED', error_msg=...`
