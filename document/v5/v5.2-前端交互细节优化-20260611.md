# Fish-Agent v5.2 前端交互细节优化

> **版本**：v5.2
> **日期**：2026-06-11
> **范围**：导航激活态 · 消息时间戳 · 代码块复制 · 路由过渡 · KeepAlive 缓存 · 移动端适配 · 全局 Escape · 上传进度 · 错误边界增强
> **前置版本**：v5.1（知识卡片体验重构）
> **修改前端文件 14 个**（新增 1 个 composable），后端无改动

---

## 一、更新目标

v5.1 完成了知识卡片的三栏布局与 SM-2 复习系统，交互框架已就绪。但从**打磨层面**看，仍存在以下体验欠账：

| 痛点 | 影响 |
|------|------|
| 导航无反馈 | 顶栏/侧栏的"知识库""知识卡片"按钮无激活态，用户不知道当前在哪个页面 |
| 页面切换生硬 | 路由跳转瞬间替换，无过渡动画，体感"硬切" |
| 聊天信息密度低 | 消息无时间戳；长回复中的代码块无法单独复制；提取按钮视觉弱 |
| 移动端粗糙 | 知识库表格溢出；卡片统计栏占太多垂直空间；详情面板无动画 |
| 会话操作隐蔽 | 侧栏操作图标（编辑/删除）hover 才显示，触屏设备找不到；重命名 blur 直接丢弃 |
| 上传无进度 | 大文件分片上传只有文字状态，看不到进度；解析中无动画反馈 |
| SSE 切页锁死 | 流式中切换页面后 `streaming` 状态未重置，导致"新对话"按钮无响应 |
| 错误边界不透明 | `onErrorCaptured` 只显示"出了点问题"，不展示具体错误信息，调试困难 |

## 三、关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 路由过渡模式 | 默认同时过渡（不用 `mode="out-in"`） | `out-in` 与 KeepAlive + 动态 key 组合会跳过进入阶段导致白屏 |
| KeepAlive 策略 | `<KeepAlive include="ChatView">` 始终存在 | 消除 v-if/v-else 分支，Transition 子节点类型始终一致 |
| 返回按钮 | 始终 `router.push('/chat')` | 用户期望明确回到对话页，非浏览器后退 |
| 代码块复制 | 事件委托 + 文字按钮 | v-html 限制无法绑 @click，事件委托绕过；文字按钮比图标更易理解 |
| 消息时间戳 | 始终显示 | 数据已就绪（`createdAt` 毫秒时间戳），灰色小字不干扰阅读 |
| 提取按钮位置 | 保持原位，仅视觉增强 | 用户决策：不移入输入栏 |

## 四、踩坑记录

### 4.1 Transition `mode="out-in"` + KeepAlive 白屏

**现象**：路由切换后页面空白，无渲染内容。

**根因**：Vue 3 的 `<Transition mode="out-in">` 在 leave 完成后挂载新节点。当直接子节点是 `<KeepAlive>` 且内部组件通过 `:key` 切换时，Transition 可能跳过进入阶段，新组件不被渲染。

**解决**：移除 `mode="out-in"`，改用默认同时过渡。为避免离开页面和进入页面同时可见造成布局跳动，给 `.page-leave-active` 加 `position: absolute; inset: 0` 让离开页面脱离文档流。

### 4.2 SSE 流式中切页导致"新对话"失效

**现象**：发送消息后（流式中），切换到其他页面再回来，点"新对话"无反应。

**根因**：`store.cleanup()` 只 abort 请求，未重置 `streaming.value = false`。`newSession()` 和 `selectSession()` 开头都有 `if (streaming.value) return` 守卫，导致所有操作被拦截。

**解决**：`cleanup()` 末尾追加 `streaming.value = false`。

### 4.3 视图组件多根节点 + Transition

**现象**：KnowledgeView 原始模板有多个根元素（AppHeader、DrawerSidebar、kb-page div），Transition 要求单根子节点。

**解决**：用 `<div class="kb-view">` 包裹整个模板，确保单根。

## 六、面试亮点

| 话题 | 核心点 |
|------|--------|
| **Transition + KeepAlive 组合陷阱** | `mode="out-in"` 与 KeepAlive 动态 key 冲突导致白屏；排查过程（逐步剥离定位到 Transition）；解决方案（默认同时过渡 + absolute leave） |
| **Pinia store 状态泄漏** | `cleanup()` 不完整导致全局 `streaming` 锁死；单例 store 的生命周期管理；`onDeactivated` vs `onUnmounted` 的区别 |
| **v-html 事件绑定** | Vue v-html 渲染的内容无法使用 `@click`；事件委托模式（父容器单一 handler + `e.target.classList.contains`） |
| **useResponsive composable** | `matchMedia` + `addEventListener('change')` + 组件卸载清理；替代各组件中散落的 `@media` 硬编码 |
| **KeepAlive include 策略** | `include` 匹配组件名实现选择性缓存；`defineOptions({ name })` 注册组件名；非匹配组件正常挂载/卸载 |
