## 改动概述

将前端从"功能可用"升级为"精致沉浸"的视觉体验：

1. **tsParticles 网络连线粒子背景** — 全局固定层，主题感知双色配置
2. **毛玻璃拟态** — 所有内容层 `backdrop-filter: blur`
3. **深色蓝紫基调** — 默认 `#0a0a14`，支持明暗切换
4. **抽屉式侧栏** — 从固定侧栏改为左滑抽屉，聊天区占满宽度
5. **共享 AppHeader** — 全局毛玻璃导航栏
6. **组件色值变量化** — 所有硬编码 RGBA 抽取为 CSS 变量

## 关键设计决策

### 1. 粒子背景 — 主题感知双色配置

`ParticleBackground.vue` 通过 `useTheme().dark` 动态切换两套 options：

| 模式 | 粒子颜色 | 连线颜色 | opacity |
|------|----------|----------|---------|
| 深色 | `#a5b4fc` `#c4b5fd` `#ddd6fe` `#e0e7ff`（亮色粒子） | `#a5b4fc` + 发光阴影 | 0.4–0.85 + 呼吸动画 |
| 亮色 | `#4338ca` `#4f46e5` `#312e81` `#3730a3`（深色粒子） | `#6366f1` | 0.25–0.55 + 呼吸动画 |

交互：鼠标 grab（吸引连线 + 高亮）+ 点击 push（添加 3 个粒子）。

### 2. 组件色值变量化

所有组件硬编码 RGBA 色值抽取为 CSS 变量，亮色主题只需覆盖变量值：

```css
--bg-header: rgba(10, 10, 20, 0.7);         /* → 亮色: rgba(255,255,255,0.8) */
--bg-input-wrap: rgba(20, 20, 35, 0.65);     /* → 亮色: rgba(255,255,255,0.9) */
--bg-suggestion: rgba(20, 20, 35, 0.6);      /* → 亮色: rgba(255,255,255,0.85) */
--bg-chat-area: rgba(10, 10, 20, 0.15);      /* → 亮色: transparent */
--border-bubble: rgba(99, 102, 241, 0.1);    /* → 亮色: rgba(0,0,0,0.06) */
```

### 3. 抽屉式侧栏

- `useDrawer` composable 管理全局 `open` ref
- `DrawerSidebar` 通过 `<Teleport to="body">` 渲染在 body 层（z-index: 30）
- 打开动画：`transform: translateX(-100%) → 0`，300ms ease-out
- 遮罩层：`rgba(0,0,0,0.45)` + `backdrop-filter: blur(4px)`
- 内容：品牌行 + 新会话按钮 → 会话列表 → 知识库上传区 → 状态栏

### 4. 知识库页渐变 Banner

- 顶部 `--gradient-brand` 紫色渐变（独立于内容区 padding）
- `::after` 伪元素实现底部渐变过渡
- 白色标题 + 白色图标按钮
- 内容区 `.kb-content` 独立 padding
