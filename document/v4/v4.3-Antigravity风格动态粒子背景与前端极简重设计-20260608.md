# v4.3 Antigravity 风格动态粒子背景 & 前端极简重设计

> 日期：2026-06-08
> 范围：前端视觉层全面重构（全局配色 + 动态背景 + 品牌标识 + 全组件黑白化）+ Antigravity 风格 Three.js 粒子系统
> 前置：v4.0 前端视觉重设计（tsParticles 蓝紫粒子 + 毛玻璃 + 渐变）

## 改动概述

v4.0 的"蓝紫基调 + 毛玻璃 + tsParticles"视觉方案虽然沉浸，但与知识工具类产品定位有偏差——装饰过重、喧宾夺主。v4.3 进行了一次从内到外的视觉重设计：

### 核心变更

1. **Antigravity 风格动态粒子背景（Three.js）** — 用 WebGL 自研粒子系统替代 tsParticles，参考 Google Antigravity 网站源码，实现超椭圆 SDF 形态渐变（圆↔菱形）+ 三色流动 + 鼠标引力连线
2. **Modern Minimalist Monochrome 配色体系** — 去掉全部毛玻璃、渐变按钮、发光阴影，改为 95% 黑白 + 5% 灰调语义色
3. **Canvas 几何鱼 logo + Space Grotesk 品牌字** — 去掉 emoji 🐟 + 渐变品牌文字
4. **全组件黑白化** — 20+ 组件从蓝紫/indigo 主题迁移到纯灰白 Token

### 版本演进

```
v4.0 → v4.1 → v4.2 → v4.3
tsParticles蓝紫粒子    Antigravity Three.js粒子
毛玻璃+渐变按钮        纯黑白Monochrome
渐变品牌文字           Canvas Logo + Space Grotesk
```

## 一、设计理念

**"Dark Canvas"** — 纯黑画布上，白色的光与雾在缓慢呼吸、漂浮、融合。

整体调性：**95% 黑白 + 5% 灰调语义色**。以灰白色系为主语言，在语义必需处（状态、代码高亮、图谱边线）保留极低饱和度的颜色暗示，兼顾极简美学与可用性。

### 核心原则

1. **去装饰**：去掉所有毛玻璃、渐变按钮、发光阴影、粒子点阵
2. **层次靠明度**：用 4 层明度梯度替代过去的 `backdrop-filter` + glow
3. **动态靠有机感**：用 Antigravity 风格 WebGL 粒子替代粗暴 tsParticles 网格
4. **色彩克制**：交互元素纯黑白，粒子用 Antigravity 源码三色方案
5. **字体即设计**：黑白设计对字体依赖更高，引入 Space Grotesk 提升品质感

## 三、Antigravity 动态粒子背景（核心）

### 3.1 设计来源

参考 Google Antigravity 网站（https://antigravity.google/）源码分析，提取粒子系统核心参数：

| 参数 | Antigravity 源码 | v4.3 实现 |
|------|------------------|-----------|
| 渲染引擎 | Three.js + 自定义 ShaderMaterial | Three.js + 自定义 ShaderMaterial |
| 粒子分布 | Poisson Disk Sampling | Poisson Disk Sampling (`poisson-disk-sampling`) |
| 相机 | `PerspectiveCamera(fov=40, z=3.1)` | 同 |
| 色彩 | 三色方案，源码：`color1=#7189ff/#2c64ed, color2=#3074f9/#f84242, color3=#000000/#ffcf03` | 暗色 `#7189ff` / `#f84242` / `#ffcf03`，亮色 `#2c64ed` / `#f84242` / `#ffcf03` |
| 形状 | 圆点 + 椭圆光斑 | 超椭圆 SDF：圆(n=2) ↔ 菱形(n=1)，鼠标距离驱动丝滑变形 |
| 连线 | 粒子间近距离连线 | 粒子间连线 + 鼠标引力线 |
| 鼠标交互 | Raycaster → 世界坐标 + 引力吸引 | 同 |

### 3.2 技术架构

```
MeshBackground.vue (Three.js WebGL)
├── 场景初始化
│   ├── PerspectiveCamera (fov=40, z=3.1)
│   ├── WebGLRenderer (antialias, DPR ≤ 2)
│   ├── Raycaster + 不可见 hitPlane (30×30)
│   └── 可视范围计算: boundsY = z × tan(fov/2), boundsX = boundsY × aspect
│
├── 粒子系统 (THREE.Points + ShaderMaterial)
│   ├── Poisson Disk Sampling 生成位置 (500×500, minDist=11, maxDist=13)
│   ├── 按可视范围拉伸 (boundsX/Y × 1.1 余量)
│   ├── 每粒子属性: aPhase, aBreathSpeed, aRotation
│   ├── 顶点着色器: 呼吸 + 鼠标吸引 + 三色流动 + morph 因子
│   └── 片段着色器: 超椭圆 SDF + 外圈光环 + 旋转
│
├── 连线系统 (THREE.LineSegments + ShaderMaterial)
│   ├── 粒子间连线 (dist < 0.18, alpha 随距离衰减)
│   ├── 鼠标引力线 (dist < 0.5, 双端渐变 alpha)
│   └── 预分配 MAX_LINES=1200 条线段的 BufferGeometry
│
├── 动画循环
│   ├── 粒子位置更新: basePosition + velocity × time + 边界循环
│   ├── 鼠标世界坐标: Raycaster + 平滑插值 (lerp 0.06)
│   ├── 连线更新: 双重循环粒子间 + 鼠标附近
│   └── visibilitychange 暂停/恢复
│
└── 主题切换
    ├── scene.background: DARK_BG=0x0a0a0a / LIGHT_BG=0xfafafa
    ├── 粒子三色切换
    └── 连线灰度切换: dark=0.55 / light=0.2
```

### 3.3 Shader 技术细节

#### 顶点着色器核心

```glsl
// 鼠标接近度 (0-1)
float mFx = smoothstep(0.6, 0.0, mDist) * uMouseActive;

// 位置吸引
pos.xy += toMouse * mFx * 0.25;

// 呼吸：靠近鼠标时更快更剧烈
float breathAmp = 0.12 + mFx * 0.18;
float breathSpd = aBreathSpeed * (1.0 + mFx * 1.5);

// 粒子尺寸：靠近鼠标放大 1.6 倍
float s = uSize * uDpr * breath * (1.0 + mFx * 1.6);

// 三色流动：三正弦波叠加 (120° 间隔)
float cp = uTime * colorSpeed + aPhase * 6.2832 + nx * 2.0;
float w1 = sin(cp) * 0.5 + 0.5;
float w2 = sin(cp + 2.094) * 0.5 + 0.5;
float w3 = sin(cp + 4.189) * 0.5 + 0.5;
vec3 col = (uColor1 * w1 + uColor2 * w2 + uColor3 * w3) / sum;

// Morph 因子传给片段着色器
vMorph = mFx;

// 旋转：靠近鼠标加速 +2.5 倍
vRotation = aRotation + uTime * (0.15 + aPhase * 0.08 + mFx * 2.5);
```

#### 片段着色器核心（超椭圆 SDF 形态渐变）

```glsl
// 超椭圆指数：n=2 圆形，n=1 菱形，中间值丝滑过渡
float n = mix(2.0, 1.0, vMorph);

// 超椭圆 SDF: |x|^n + |y|^n
float sd = pow(abs(ruv.x), n) + pow(abs(ruv.y), n);

// 核心形状
float core = smoothstep(0.5, 0.18, sd);

// 鼠标附近外圈光环
float halo = smoothstep(0.55, 0.25, sd) * smoothstep(0.25, 0.08, sd) * vMorph * 0.7;

float alpha = core + halo;
```

**形态渐变原理**：

- 超椭圆方程 `|x|^n + |y|^n = 1` 中，`n=2` 为标准圆形，`n=1` 为菱形
- `vMorph` 由鼠标距离 `smoothstep(0.6, 0.0, dist)` 驱动
- 远离鼠标 → `vMorph=0` → `n=2` → 完美圆形
- 贴近鼠标 → `vMorph=1` → `n=1` → 菱形
- 中间值 → 圆↔菱形之间丝滑过渡，无跳变

### 3.4 三色流动方案

从 Antigravity 源码提取的三色配色：

| 模式 | Color 1 | Color 2 | Color 3 |
|------|---------|---------|---------|
| 暗色 | `#7189ff` (蓝) | `#f84242` (红) | `#ffcf03` (黄) |
| 亮色 | `#2c64ed` (深蓝) | `#f84242` (红) | `#ffcf03` (黄) |

颜色流动通过三正弦波叠加实现（120° 间隔），归一化后平滑混合：

```
colorSpeed = 0.4 + mFx * 0.6     // 基础速度 0.4，鼠标附近加速到 1.0
phase = time × speed + particlePhase × 2π + spatialX × 2
w1 = (sin(phase) + 1) / 2
w2 = (sin(phase + 2π/3) + 1) / 2
w3 = (sin(phase + 4π/3) + 1) / 2
finalColor = normalize(color1 × w1 + color2 × w2 + color3 × w3)
```

### 3.5 连线系统

| 类型 | 范围 | 最大 alpha | 模式 |
|------|------|-----------|------|
| 粒子间 | `dist < 0.18` | 暗色 0.12 / 亮色 0.08 | 距离线性衰减 |
| 鼠标引力 | `dist < 0.5` | 暗色 0.25 / 亮色 0.15 | 粒子端全 alpha，鼠标端 30% alpha |

预分配 `MAX_LINES=1200` 条线段（每条 2 点 × 3 坐标），`setDrawRange` 控制实际绘制范围。

### 3.6 性能保障

| 策略 | 说明 |
|------|------|
| Poisson Disk Sampling | 均匀分布，避免聚簇，~2000 粒子 |
| DPR 上限 | `Math.min(devicePixelRatio, 2)` |
| visibilitychange 暂停 | 标签页不可见时 `clock.stop()` |
| 连线上限 | MAX_LINES=1200，超出丢弃 |
| NormalBlending | 不使用 AdditiveBlending，避免过曝 |
| 模块级变量 | scene/camera/renderer 等提升为模块级，避免 GC |

## 十、关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 粒子引擎 | Three.js + 自定义 Shader | 忠实还原 Antigravity 效果；ShaderMaterial 灵活控制形态/颜色/连线 |
| 粒子分布 | Poisson Disk Sampling | 均匀随机分布，避免聚簇和空洞，Antigravity 源码同款 |
| 形态变化 | 超椭圆 SDF (n=2→1) | 数学上丝滑：`pow(\|x\|, n) + pow(\|y\|, n)` 一条曲线控制圆↔菱形 |
| 颜色流动 | 三正弦波叠加 | 120° 间隔产生三色自然循环，归一化确保平滑过渡 |
| 连线渲染 | LineSegments + 预分配 | 比逐条创建 THREE.Line 高效，单次 draw call |
| 配色体系 | 95% 黑白 + 5% 灰调语义色 | 知识工具类产品，装饰不喧宾夺主 |
| Logo | Canvas 2D 绘制 | 纯代码，无图片依赖，尺寸/颜色可编程控制 |
| 品牌字体 | Space Grotesk | 无衬线几何字体，黑白设计下提升品质感 |

## 十一、实现过程中解决的问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 粒子区域只是一个正方形 | Poisson 采样在 [-1,1]²，未按相机可视范围拉伸 | 计算 `boundsX/Y = z × tan(fov/2) × aspect`，拉伸采样 + 10% 余量 |
| 颜色随时间变化不明显 | `uTime × 0.03` 速度太慢 | 提高到 0.4 + 每粒子 phase 偏移 + 鼠标附近加速 |
| 颜色过渡突变 | `if/else` 分段赋值 | 三正弦波叠加归一化，0°/120°/240° 间隔 |
| 粒子速度累积 | `pos += velocity × uTime` 加速 | 改为 `basePosition + velocity × time`，从 JS 端每帧计算 |
| "一坨恶心的发光物" | AdditiveBlending + glow shader + shadowBlur | NormalBlending + 去掉发光 + 粒子尺寸控制在 2.5px |
| 形状随机不规则 | 固定 `aShapeType` 属性随机分配 | 改为超椭圆 SDF，`n = mix(2.0, 1.0, mouseProximity)` 鼠标距离驱动 |
| 暗色背景上 `#000000` 粒子不可见 | 源码 color3 在暗色模式为纯黑 | 暗色模式只使用三色亮色方案 `#7189ff` / `#f84242` / `#ffcf03` |
| TypeScript 类型缺失 | `poisson-disk-sampling` 无 @types | 自建 `types/poisson-disk-sampling.d.ts` 声明文件 |
