### 知识库异步链路优化：自适应处理流水线 (Adaptive Routing)

- **痛点：** 所有 PDF 无脑上 300dpi 视觉 OCR 解析，虽然解决了乱码问题，但极大浪费了 GPU/CPU 算力，导致整体摄入延迟偏高。
- **演进方案：** 引入 **基于 ROI 的自适应路由机制**。
  - 在 Python Worker 消费前加入轻量级的前置图像检测（如 OpenCV 计算清晰度评分）。
  - **快速通道 (Fast Lane)：** 清晰度高的电子件/标准件，降级走 200dpi OCR，极速处理。
  - **高精度通道 (Heavy Lane)：** 模糊、噪点多的实拍件，走 300dpi 甚至叠加图像增强（去噪/二值化）再解析，确保 P99 准确率。

### RAG 召回性能与成本控制：语义路由 (Semantic Router)

- **痛点：** 粗粒度的全量并发检索会带来不必要的系统读压力；用大模型判断用户意图又会导致延迟和 Token 成本双高。
- **演进方案：**
  - 前置一个轻量级小模型（如 Qwen-1.5B），将 `temperature` 锁死在 0，强制输出确定性的意图分类结果。
  - 日常闲聊直接被拦截并交由 Redis 短期记忆处理；只有被判定为“复杂信息获取”时，才放行触发底层的 ES/Redis 向量多路并发召回与查询扩展（Query Expansion）。
